# 艾琳

> 反手能力无敌，勾引包围再消灭。本质是打经济压制。

## 核心思路
- 敢于A人勾引，**肉身开团**，补足开团能力不足的缺点
- 对面追你，就陷入包围圈，几波之后对面不敢和你打
- 一定不要先用技能，留来**打反手**
- 前期有优势，充分帮队友扩大优势；围绕资源打（4分钟控龙）

## 快速清线手法（顶级实践）

**清线公式：AAA → 2 → A → 1 → A**

- 摸到兵线立刻起手，不等兵线满屏
- 清线同时就能对对手形成威胁：艾琳滑动有操作空间，追我的人大概率要到塔下
- **关键**：清线过程中留眼看对方控制技能，提前走位躲避，不要被 CC 打断位移

## 对线压制节奏（顶级实践）

每一波出手前必过三问：
```
1. 对面中单现在在哪？
2. 对面打野现在在哪？
3. 对面有哪些关键技能还在 CD？我怎么用走位躲？
```
三问全有答案 → 主动打压 | 有一条不确定 → 只清线，不激进

## 优势局行为规范
- 经济领先 ≥ 2000 时，强制进入**收割模式**，降低激进程度
- 领先时默念：**"活着比击杀更重要"**
- 禁止：敌方人数未清楚时追击、残血独自深入、团战站位最前

## 团战跟进
- 队友发动后 **3秒内必须跟进**，不能在远处单独输出
- 跟着队友蹲草，不做孤狼
- 保持在技能最大射程 80% 处输出，不贴脸

## 已识别问题与对策

### 问题一：前期压线追杀导致反被击杀
- **根因**：把压线目标从"经济压制"偷换成了"击杀"，追击过深被中单/打野收
- **对策**：压线收益 = 对面补不到刀 + 磨塔皮 + 吃附近野怪。清完线后回安全位置，不追残血
- **口诀**：**"他补不到刀，我就已经赢了"**

### 问题二：闪现大招1换1
- **根因**：上头后用先手思维玩后手英雄，违背"留技能打反手"的核心
- **对策**：闪现只保命，大招只反手（对面冲你时用）。1换1对射手是净亏——你死了团战就没输出
- **口诀**：**"闪现是保险，不是武器"**
