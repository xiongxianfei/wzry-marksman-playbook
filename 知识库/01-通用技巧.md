# 通用技巧

## 一、零和博弈思维

发育路不只是"我要刷钱"，而是**我刷钱的同时让对面拿不到钱**：

| 主动行为 | 对面承受的损失 |
|---------|-------------|
| 压制对方射手出不了塔 | 对方损失兵线经济 |
| 争夺小龙/河蟹 | 对方损失资源加成 |
| 4分钟去暴君附近施压 | 对方被迫回防，损失野区 |
| 优势时反蹲打野路径 | 对方打野经济中断 |

- 被动苟住 → 双方经济差距维持不变
- 主动施压 → 每一次对线胜利都在**扩大经济差**
- 打凶的前提是**有经济支撑**，三件套前打凶，三件套后打穿

---

## 二、经济节奏

### 抢先清线
- 主动迎兵线，不要等线过来
- 清完立刻评估：野区有野怪？河蟹刷新？支援队友？
- 己方兵线推过去 → 对面塔下补刀效率下降，你已经去拿别的了

### 发育循环
- 一波兵线 + 一波野怪交替，保持连续经济
- 每一波线结束，立刻想**下一波钱从哪里来**
- 帮打野清野怪蹭经济
- 有钱的团才去打，没钱不要强行参与

### 出装检查点
| 时间 | 目标 |
|------|------|
| 4分半 | 第1件成装 + 鞋 |
| 7分半 | 第2件成装 + 鞋 |
| 10分半 | 第3件成装（三件套） |
| 12分钟 | 换抵抗鞋（按需） |

### 并线时机
- 4分钟后考虑占中线（视野 + 让队友抱团 + 大招命中率高）
- 队友进攻时去反推对面线，不无效堆叠

---

## 三、防抓意识

- **1分15秒**：第一波防抓点，确认对面打野位置
- **第2波兵线**：注意中路支援
- **第3波兵线**：注意打野4级后 gank
- 10分钟前后最危险，注意视野盲区
- 兵线消失后留 **2秒假视野** 再移动，不暴露行动路线

---

## 四、出手前五秒信息核查

> 用有心算无心，知己知彼百战百胜。

```
1. 对面射手位置？          → 知道在哪，才知道能不能追
2. 对面中路有没有漏视野？  → 漏了才能放心打，没漏就留后手
3. 对面打野有没有漏视野？  → 不知道打野在哪，禁止激进
4. 对面哪些关键技能还在？  → CD没好，才是出手窗口
5. 我的走位能规避关键技能吗？→ 想好被动预案再打
```

**全部有答案 → 出手 | 有一条不确定 → 先蹭视野**

---

## 五、血量即权力

- 血量高 = 有主动权；血量低 = 被迫守塔，对面在拿资源
- 消耗战中每一滴血都值钱，保持高血量本身就是一种施压
- 血量 < 60% 主动拉开距离回复
- 高血量 = 随时能参与资源团，低血量 = 只能看

---

## 六、推塔意识

- 经济优势必须转化为**地图优势**才能赢，手段就是推塔
- **击杀后第一反应：先推塔，再追击或发育**
- 推掉塔后，己方兵线自动施压，你才能安全做其他事
- 塔推得越早，对面安全区越小，你的行动自由度越大

---

## 七、跟强打

> 把鸡蛋放在最强的篮子里。

**实战验证：劣势局紧跟打野成功翻盘；优势局孤立发育反被翻盘。**

```
打野有经济优势？    → 跟打野
中路击杀数领先？    → 靠近中路发育
对面某条线在崩？    → 配合队友去收割那条线
没有明显强势方向？  → 默认跟打野，因为打野覆盖全图
```

- 清完线立刻看打野位置，往他那边靠
- 打野准备进攻时，你不能还在另一条线清兵
- 打野强势 → 你跟着拿资源 → 经济双双领先 → 雪球越滚越大

---

## 八、资源决策

### 暴君/主宰决策三问
```
1. 血量 < 40%？     → 不打
2. 人数劣势？       → 不打
3. 对面核心位置不明？→ 不打
三问全过 → 打 | 任意一问否 → 撤
```

- 10分钟节点：一波暴君 + 一波主宰，游戏基本结束
- 9分钟主动靠近队伍布局
- 优势局耐住性子，打资源团而非盲目压人

---

## 九、团战站位

- 永远站在**队友身后1个身位**，在技能最大射程 80% 处输出
- **后手进场**：不让刺客预判位置，兵线消失后留2秒假视野
- 坦克建立威胁后再跟进输出
- 团战前先找"哪个敌方英雄会切我"，预判路径
- 目标优先级：风险人物（刺客/高爆发）> 切对方后排

---

## 十、进阶操作

### 一秒换装
- 提前存好装备方案，商店停留 ≤ 3 秒
- 利用**复活甲生效期间**主动换装

### 走A技巧
- 松开方向盘后 A，略微移动再松开，输出次数更多
- 空中走A同理

### 视野切换
- 团战前切全图视野判断敌方核心位置
- 大位移后拉视角找墙/落点，不靠感觉

---

## 十二、优势扩张：抱团推进与入侵

> 实战验证：5连胜核心手感 —— 有优势就靠队友，不要独自发育。

### 触发条件（满足任意一条，立刻切换到抱团模式）

| 信号 | 行动 |
|------|------|
| 己方经济领先 ≥ 2000 | 停止单打，找队伍 |
| 本线对面射手已死/回城 | 推完兵线立刻去支援 |
| 刚赢一波团战 | 不分散，一起推塔 |
| 10分钟节点到了 | 无论有没有优势，都靠过去 |

---

### 抱团推进节奏

```
清完本线兵 → 看队友位置 → 往最近的队友靠
      ↓
集合后的优先级：
  有塔可推？ → 5人一起推塔
  无塔可推？ → 入侵对方野区抢资源
  暴君/主宰刷新？ → 提前集合卡时间点
```

**关键习惯：快速靠拢，不等队友来找你，你主动去找队友**

---

### 入侵野区（优势时的主动骚扰）

优势后不只是推塔，还要**进入对方野区制造压力**：

1. **扫视野** → 先插眼或用技能探路，不盲目进
2. **抢野怪** → 进一步拉大经济差，逼对方出来防守
3. **创造接触** → 对面为了保野区被迫出来 → 创造团战机会
4. **不贪进** → 打完就退，不深入没视野的区域

> 入侵的本质：用地图压力把对面逼出来，而不是等他们来送。

---

### 射手在抱团中的定位

| 阶段 | 行动 |
|------|------|
| 集合途中 | 顺路清掉自己线的兵，不绕路 |
| 推塔过程 | 站坦克/战士后面输出，坦克先进你再跟 |
| 团战结束 | **立刻 A 塔**，不追击逃跑的敌人 |
| 塔推倒后 | 退出来等兵线刷新，不盲目进高地 |

---

### 优势局最常见的翻盘原因

| 错误行为 | 导致结果 |
|---------|---------|
| 有优势还继续单打 | 对面各自发育追上来 |
| 团战赢了去追击而非推塔 | 浪费窗口期，对面复活拿资源 |
| 进高地前没有清外围视野 | 被埋伏反杀，优势崩盘 |
| 等对面送头而不主动施压 | 给对面喘息空间 |

**核心认知：优势不会自动变成胜利，必须通过持续抱团施压来"兑现"它。**

---

## 十一、每局必做清单

**开局前：** 选定本局专注练习的 1 个技能点

**游戏中：**
- [ ] 主动迎兵线，清完立刻走人
- [ ] 出手前过五秒信息核查
- [ ] 9分钟靠近队伍，看打野位置

**游戏后（2分钟复盘）：**
- [ ] 10分钟经济达到 6500 了吗？
- [ ] 有没有不必要的死亡？
- [ ] 打暴君前用了决策三问吗？
- [ ] 有没有孤立发育而不跟打野？
- [ ] 有优势时有没有及时抱团推进？（而非继续单打）
- [ ] 今局英雄专项问题有没有犯？
