# 后羿

> 三件套撑起中后期，控距点人。量变到质变的英雄。

## 核心思路
- 前期以发育控资源为主，**10分钟三件套**作为中后期支柱
- 出攻速鞋 + 末世，直接强势对A，有伤害且有续航
- 一波线一波野怪的节奏

## 出装检查点
| 时间 | 目标 |
|------|------|
| 4分半 | 第1件成装 + 鞋 |
| 7分半 | 第2件成装 + 鞋 |
| 10分半 | 第3件成装（三件套） |
| 12分钟 | 换抵抗鞋 |

## 技巧
- 锁定后排兵/炮车，一技能快速清一波线
- 二技能补刀
- 平A和二技能叠加爆发，抢夺资源
- 无伤点塔：控好距离，不被反打

## 站位原则
- 永远站在队友身后，禁止无掩护站前排输出
- 控制距离点人，不贴脸
