# 莱西奥

> 先 poke 后起飞，32起手打团。到最后都变成了计算。

## 当前评分
- 前期对线：80分
- 中期资源团战：70分
- 后期极限操作：60分

## 技能使用规范

### 二技能（飞行）
- 落点必须有预判，"落地后能打几下？"答案是0则不飞
- **先 poke 后起飞**，不无脑起飞
- 飞起来后拉视角找墙，不靠感觉
- 32起手：飞得更久，用于**团战**
- 23起手：瞬间爆发，用于**秒人**
- 飞起来走A：松开方向盘后A，略微移动再松开，次数更多

### 一技能
- 有队友在场 或 目标血量 < 30% 才主动出技能
- 前期（1-6分钟）只用普攻 + 一技能骚扰，不轻易飞入敌阵

### 大招
- 目标被控？我的位置安全？队友跟上？三个都满足再放
- 大招目标命中率目标：≥ 70%

## 团战要点
- **后手进场**：不漏视野给刺客，团战晚点进入，先找好位置
- 比前排后退1个身位，不站第一被集火位
- 团战前视角归零，找墙位，背靠地形作战
- 不该A塔的时候别A塔，有推塔需求时用好推塔键

## 一秒换装
- 复活甲生效期间主动换装（不要发呆看局势）
- 提前存好装备方案

## 常见失误（对照复盘）
- [ ] 本局有没有因乱飞导致死亡？
- [ ] 大招有没有浪费？
- [ ] 有没有兵线消失后马上移动（暴露位置）？
