# 核心原则（每局前30秒速览）

---

## 底层逻辑

> 顶级发育路的"凶"是有算计的凶，不是莽。

**三重优势叠加后才出手：**

```
信息优势（知道对面中单/打野/技能CD在哪）
    +
地形优势（清完线、摸到兵线、有操作空间）
    +
人数优势（靠队友，你只需补伤害）
    ↓
三重叠加 → 主动出手
缺少任意一重 → 只清线，不激进
```

射手的本质不是孤狼单杀，而是**用算计消灭风险，再用后手收割确定收益**。

---

**1. 活着才有经济**
死亡率第一优先，输出建立在不死的基础上。

**2. 这是零和博弈**
你不抢的资源对面就在拿。苟活不等于赢，要主动破坏对方的经济节奏。

**3. 抢先清线**
主动迎兵线，清完立刻走人。等线 = 浪费时间，时间差就是经济差。

**4. 出手前先过五秒信息核查**
```
对面射手在哪？中路漏视野？打野漏视野？关键技能CD在不在？走位预案有吗？
全部有答案 → 出手 | 有一条不确定 → 先蹭视野
```

**5. 血量即权力**
血量 < 60% 主动拉开回复。高血量 = 随时能参与资源团。

**6. 击杀后先推塔**
击杀是锦上添花，推塔才是真正的雪球。

**7. 跟强打，默认跟打野**
清完线立刻看打野位置，往他那边靠。不知道跟谁就跟打野，因为打野覆盖全图。

**8. 10分钟是关键节点**
9分钟靠近队伍，一波暴君 + 一波主宰，游戏基本结束。

**9. 暴君决策三问**
```
血量 < 40%？→ 不打
人数劣势？  → 不打
不知道对面核心在哪？→ 不打
```

**10. 有优势就抱团，不单打**
经济领先/赢完一波团战 → 立刻靠队伍，推塔入侵对面野区，不要继续单线发育。优势不会自动变成胜利，必须靠持续抱团施压来兑现。

**11. 气沉丹田，用核心力量**
不上头，不用心力打游戏。选定本局 1 个练习点，打完就复盘。
