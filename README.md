# wzry-marksman-playbook

王者荣耀发育路（射手）系统化训练体系。通过结构化知识库 + 每局数据记录 + Python 数据分析，把"感觉打得好/不好"变成可量化、可追踪的进步曲线。

---

## 项目结构

```
├── 知识库/
│   ├── 00-核心原则.md        每局前30秒速览，10条核心原则
│   ├── 01-通用技巧.md        完整通用知识（经济/视野/团战/推塔等）
│   └── 英雄手册/
│       ├── 后羿.md
│       ├── 莱西奥.md
│       ├── 艾琳.md
│       ├── 戈娅.md
│       └── 孙尚香.md
│
├── 原始笔记/
│   └── 王者荣耀.md           实战心得，只追加不修改
│
├── 生成模板.py               生成 Excel 记录表
├── 分析数据.py               读取记录表，生成分析报告
├── 训练记录.xlsx             每局数据记录（运行生成模板.py 后得到）
└── 分析报告.png              最新分析报告（运行分析数据.py 后得到）
```

## 快速开始

**环境依赖（一次性安装）：**
```bash
pip install -r requirements.txt
```

**第一次使用，生成记录表：**
```bash
python 生成模板.py
```

**每局打完后：**
打开 `训练记录.xlsx` → 在「每局记录」Sheet 填一行，复盘分自动计算。

| 字段 | 填写方式 | 说明 |
|------|---------|------|
| 日期 | 手动输入 | 如 2026-03-28 |
| 英雄 | 下拉选择 | 后羿/莱西奥/艾琳/戈娅/孙尚香 |
| 胜负 | 下拉选择 | 胜/负 |
| 10分钟经济 | 手动输入 | 游戏结束后查战绩 |
| 死亡次数 | 手动输入 | |
| 暴君参与～心态稳定 | 下拉选择 | 是/否，6项 |
| 备注 | 手动输入 | 一句话：今局最大问题或收获 |

**想看进度时：**
```bash
python 分析数据.py
```
生成 `分析报告.png`，包含关键数字、趋势图、英雄胜率、能力雷达图。

## 复盘评分体系（满分100分）

| 维度 | 分值 | 评分标准 |
|------|------|---------|
| 10分钟经济 ≥ 6500 | 15分 | |
| 死亡次数 ≤ 2 | 10分 | |
| 暴君/主宰参与 | 10分 | |
| 打暴君前执行决策三问 | 10分 | |
| 9-12分钟靠近队伍 | 10分 | |
| 击杀后推塔 | 10分 | |
| 清线后跟强打 | 10分 | |
| 心态稳定（无冲动死亡/无优势送头） | 15分 | |
| 备注不为空（有复盘意识） | 10分 | |

**评级：** `< 60` 重点复盘 · `60-79` 正常局 · `≥ 80` 优秀局

## 数据复盘原则

### 原则一：看趋势，不看单局

单局受队友、英雄池、对位的影响太大，一局高分不代表进步，一局低分不代表退步。
**正确做法：看连续10局以上的均值是否在上升。**

关键信号：
- 10分钟均经济连续上升 → 发育习惯在改善
- 均死亡次数下降 → 生存意识在提升
- 均复盘分低于60 → 说明有系统性问题，需要找规律而非个案

---

### 原则二：经济是一切的前置指标

经济差距决定团战胜负，团战胜负决定资源归属，资源归属决定游戏结果。
**10分钟经济是最核心的单一指标，优先保证它。**

复盘时的经济问题归因链：
```
经济不达标
  ├── 死亡次数多？      → 生存问题，看被杀原因
  ├── 兵线有断？        → 发育节奏问题，是否在等线
  ├── 参与了无意义团战？ → 决策问题，团战前有没有评估经济
  └── 野区资源没拿？    → 是否在清线后及时去野区
```

---

### 原则三：死亡要分类，不是所有死亡都一样

复盘死亡时区分两类，处理方式完全不同：

| 类型 | 定义 | 处理方式 |
|------|------|---------|
| **可避免的死亡** | 视野缺失时推进、优势贪打追击、无队友保护站前排 | 这是习惯问题，下局刻意避免 |
| **不可避免的死亡** | 队友失误导致被切、必要的换家 | 接受，不影响心态 |

**只有"可避免的死亡"才值得复盘，不要为不可控的死亡内耗。**

---

### 原则四：胜率不是核心指标（短期内）

胜率受队友影响50%以上，不能反映个人进步。
**真正反映进步的是：在相同局面下，你的经济和复盘分是否在提升。**

正确的进步判断标准：
- 输了但10分钟经济达标、死亡≤2 → 这是好的失败，说明个人发挥正常
- 赢了但经济不达标、死亡很多 → 这是坏的胜利，靠队友赢的，问题没有暴露

---

### 原则五：找重复出现的问题，忽略偶发问题

每周复盘时，看备注栏，**连续3局以上出现的问题才是真正需要解决的问题。**

复盘流程（每周日，10分钟）：
1. 打开「周统计」Sheet，看6个核心数字
2. 找本周最低的1-2个维度
3. 翻备注栏，找重复出现的关键词
4. 下周只专注解决这1-2个问题

---

### 原则六：用数据验证认知，而不是用感觉

常见的感觉陷阱：
- "感觉这周打得不错" → 看均复盘分，是不是真的在60以上
- "感觉后羿更顺手" → 看各英雄胜率，数据说话
- "感觉暴君总是被抢" → 看暴君参与率，低于50%才是真问题

**每次对自己的游戏有判断，都去数据里验证一次。**

---

### 复盘节奏建议

| 频率 | 时长 | 内容 |
|------|------|------|
| 每局后 | 1-2分钟 | 填一行数据 + 一句话备注 |
| 每周日 | 10分钟 | 看周统计，找重复问题，定下周专项 |
| 每月底 | 30分钟 | 看月度趋势，更新英雄手册，淘汰无效认知 |
