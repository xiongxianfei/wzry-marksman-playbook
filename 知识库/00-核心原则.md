## 底层逻辑

> 顶级发育路的"凶"是有算计的凶，不是莽。

**三重优势叠加后才出手：**

```
信息优势（知道对面中单/打野/技能CD在哪）
    +
地形优势（清完线、摸到兵线、有操作空间）
    +
人数优势（靠队友，你只需补伤害）
    ↓
三重叠加 → 主动出手
缺少任意一重 → 只清线，不激进
```

射手的本质不是孤狼单杀，而是**用算计消灭风险，再用后手收割确定收益**。

## 射手12大法则

**法则一：射手只打正面团，不打多方位**
团战前找好站位，确保输出方向在正面。被多方向包夹时立刻撤，不在包围中输出。

**法则二：抢先清线，不等线来**
主动迎兵线，清完立刻走人。等线 = 浪费时间，时间差就是经济差。

**法则三：找好对方辅助位置，防中单 gank**
出手前先确认辅助在哪，辅助不明 = 禁止激进。

**法则四：血量即权力，低血不出手**
血量 < 60% 主动拉开回复。低血量无法参与任何资源团，等于主动放弃权力。

**法则五：无中立资源且有河道视野，优先转中发育**
本线资源清空且河道视野安全时，转中比原地等下一波更值。有河道视野 = 路上安全，可以放心转。

**法则六：击杀后先推塔，不追击**
击杀是锦上添花，推塔才是真正的雪球。窗口期有限，塔比人头更重要。

**法则七：清完线立刻靠打野**
不知道跟谁就跟打野，打野覆盖全图。射手孤立 = 最高风险状态。

**法则八：有优势抱团推进，不孤立发育**
经济领先或赢完一波团战 → 立刻靠队伍。优势不会自动变成胜利。
> 打暴君/主宰前三问：血量 < 40%？人数劣势？对面核心不明？任意一条成立 → 不打。

**法则九：那座塔凸出来，推那座塔**
抱团后优先打地图上最突出的一座塔——它离我们最近、对面最难防守、推掉后对面阵线整体后退。不要分兵去推"看起来有机会"的塔。

**法则十：三重优势叠加才出手**
信息优势（知道对方位置）+ 地形优势（清完线有操作空间）+ 人数优势（靠队友）→ 三重叠加才激进，缺一重只清线。

**法则十一：待补充**

**法则十二：顺风保两条优势线，逆风保一条优势线**
```
顺风局：至少维持两条线的推进优势，逼对面多点防守，无法集中兵力
逆风局：收缩资源，集中维持一条线不崩，以此为支点等待翻盘机会
```
优势线 = 己方兵线推过河 / 己方塔还在 / 对面塔已倒。宁可放弃没优势的线，不要两头都撑、两头都烂。
