# 公孙离

> 强势对点英雄，利用位移制造压迫感，前期用换血节奏建立优势。

## 核心思路

- 前期核心打法：**让一兵 → 狂暴 → 平A → 2技能往前顶**
- 利用对面后排两个兵残血，对手不得不和我们对点强换状态
- 本质：**用有利换血逼迫对方进入被动**，而非直接追杀
- 位移灵活，进退自如，适合贴脸后快速撤退

## 前期换血节奏

```
己方一兵让给对面（诱导对面后排追兵线）
    ↓
对面后排两兵残血
    ↓
触发狂暴（被动叠层或主动触发）→ 平A → 2技能往前顶
    ↓
对面被迫对点还手（不还就损血吃亏）
    ↓
我方换血合算 → 逐渐建立血量优势
```

**关键逻辑：** 让一兵是主动创造换血条件，不是浪费兵线。对面如果不还手，我们继续吃兵线占便宜；对面如果还手，我们换血合算。这是一个必赢的选择题。

## 技能使用规范

- **2技能（往前顶）**：用来跟进平A，不要第一时间用来逃跑
- **狂暴（被动）**：换血前确认叠层数，满层再出手收益最大
- **大招**：保留到对面关键位移/技能用完后再接

## 对线注意

- 出手前仍需过三问：辅助在哪？中单有没有视野？打野漏了吗？
- 换血后血量 < 60% → 立刻拉开，不贪第二波
- 对面有控制技能时，2技能往前顶要预判 CC 方向

- [ ] 换血后有没有及时撤退，避免被反打？
